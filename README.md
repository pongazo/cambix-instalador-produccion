# Cambix para Windows: instaladores

Aquí se publican los instaladores de Cambix para Windows (la app de las cajas), y desde aquí la app
se actualiza sola.

- Cada versión va en **Releases**, con su instalador (`Cambix-X.Y.Z-instalador.exe`).
- Este repositorio no tiene el código de Cambix: solo los instaladores.
- Para operar, una caja necesita un código de autorización que entrega el Administrador de la casa
  en Administración › Equipos autorizados.
